## Core Identity Types

### `SolidId`
Opaque identifier for a 3D solid loaded from STEP.

```typescript
type SolidId = string; // UUID v4
```

**Lifecycle**: Created by `clean_geometry`. Invalidated when `rollback` restores a prior snapshot.  
**Scope**: Session-scoped; not persisted to disk.

---

### `ShellId`
Opaque identifier for a decomposed shell (panel).

```typescript
type ShellId = string; // UUID v4
```

**Lifecycle**: Created by `decompose_volume`. May be replaced by `booleanCut` operations.  
**Parent**: Always associated with a `SolidId`.

---

### `UnfoldId`
Opaque identifier for a 2D flat pattern generated by `apply_unfold`.

```typescript
type UnfoldId = string; // UUID v4
```

**Lifecycle**: Created by `apply_unfold`. Used by `simulate_nesting` and `export_production_pack`.  
**Shape**: Contains flat width/height dimensions and DXF wire geometry reference.

---

### `NestId`
Opaque identifier for a nesting layout.

```typescript
type NestId = string; // UUID v4
```

**Lifecycle**: Created by `simulate_nesting`. Used by `export_production_pack`.  
**Contains**: Material utilization %, sheet dimensions, panel placement coordinates.

## Snapshot & Rollback

### `GeometrySnapshot`
Captures the full geometry state at a point in time to support rollback.

```typescript
interface GeometrySnapshot {
  snapshotId: string;        // UUID v4
  solidIds: SolidId[];       // All solid IDs at snapshot time
  shellIds: ShellId[];       // All shell IDs at snapshot time
  timestamp: number;         // Unix epoch ms
  operationLabel: string;    // Human-readable label (e.g., "before decompose_volume")
}
```

---

### `RollbackToken`
Opaque token returned with each mutating operation to enable rollback.

```typescript
type RollbackToken = string; // UUID v4 — references a GeometrySnapshot
```

**Rule**: Every mutating MCP tool MUST return a `rollback_token` (Constitution Principle IV).

## Manufacturing Configuration

### `ManufacturingConfig`
Aggregated configuration loaded from `config.yaml`.

```typescript
interface ManufacturingConfig {
  materials: MaterialSpec[];
  tooling: ToolingCapability;
  logistics: LogisticsConstraints;
  environmental: EnvironmentalContext;
}
```

---

### `MaterialSpec`
Physical properties of a sheet metal material.

```typescript
interface MaterialSpec {
  id: string;               // e.g., "mild_steel_1.5mm"
  name: string;             // e.g., "Mild Steel 1.5mm"
  thicknessMm: number;      // Sheet thickness in mm
  kFactor: number;          // Neutral axis coefficient (default: 0.33)
  yieldStrengthMpa: number; // Material yield strength
  grainDirection: 'x' | 'y' | 'any';
  inventorySheets: SheetSize[];
}

interface SheetSize {
  widthMm: number;
  heightMm: number;
  label: string;            // e.g., "4x8ft", "A0"
}
```

---

### `ToolingCapability`
Press brake specifications and cutting tool constraints.

```typescript
interface ToolingCapability {
  pressBrake: {
    maxTonnage: number;           // kN
    maxBendLength: number;        // mm
    vDieWidths: number[];         // mm list (e.g., [6, 8, 10, 16])
    punchRadii: number[];         // mm list (e.g., [0.5, 1.0, 2.0])
  };
  laser: {
    maxKerfWidthMm: number;       // Laser kerf (default: 0.15 mm)
    minHoleDiameterMm: number;    // Must be >= material thickness
  };
}
```

---

### `LogisticsConstraints`
Physical shipping and handling limits.

```typescript
interface LogisticsConstraints {
  shippingEnvelope: {
    maxLengthMm: number;
    maxWidthMm: number;
    maxHeightMm: number;
  };
  maxWeightKg: number;          // Ergonomic limit (default: 23 kg)
  coatingEnvelope: {
    maxLengthMm: number;
    maxWidthMm: number;
  };
}
```

---

### `EnvironmentalContext`
Functional constraints affecting material and joint type selection.

```typescript
interface EnvironmentalContext {
  fireRated: boolean;       // Blocks adhesive and plastic fasteners (Constitution Principle III)
  marineGrade: boolean;     // Requires corrosion-resistant materials
  highVibration: boolean;   // Requires mechanical fasteners; no adhesives
}
```

## Feature Extraction

### `FeatureSet`
Result of the Anti-Corruption Layer feature extraction pipeline.

```typescript
interface FeatureSet {
  shellId: ShellId;
  bends: BendFeature[];
  holes: HoleFeature[];
  flanges: FlangeFeature[];
  reliefs: ReliefFeature[];
}
```

---

### `BendFeature`
Detected bend in a sheet metal panel.

```typescript
interface BendFeature {
  featureId: string;
  angleDeg: number;           // Bend angle (0–180°)
  radiusMm: number;           // Inner bend radius
  lengthMm: number;           // Bend line length
  kFactor: number;            // K-factor applied
  bendAllowanceMm: number;    // Computed bend allowance
  faceIds: string[];          // OCCT face IDs adjacent to bend
}
```

---

### `HoleFeature`
Detected hole in a sheet metal panel.

```typescript
interface HoleFeature {
  featureId: string;
  centerX: number;
  centerY: number;
  diameterMm: number;
  throughHole: boolean;
  faceId: string;
}
```

---

### `FlangeFeature`
Detected flange (planar face adjacent to a bend).

```typescript
interface FlangeFeature {
  featureId: string;
  widthMm: number;
  lengthMm: number;
  adjacentBendId: string;
  faceId: string;
}
```

---

### `ReliefFeature`
Corner relief cut added to prevent tearing at bend intersections.

```typescript
interface ReliefFeature {
  featureId: string;
  type: 'dogbone' | 'circular';
  radiusMm: number;
  locationX: number;
  locationY: number;
}
```

## Export & Job Lifecycle

### `ExportResult`
Files produced by a completed `export_production_pack` job.

```typescript
interface ExportResult {
  jobId: string;
  files: ExportFile[];
  totalTimeMs: number;
}

interface ExportFile {
  type: 'dxf' | 'step' | 'bom_csv' | 'assembly_json' | 'svg_preview';
  path: string;             // Relative path within export archive
  sizeBytes: number;
}
```

---

### `ExportJob`
Internal job lifecycle state (not exposed directly in MCP responses).

```typescript
interface ExportJob {
  jobId: string;
  status: 'queued' | 'running' | 'succeeded' | 'failed';
  progress: number;         // 0–100
  createdAt: number;
  completedAt?: number;
  result?: ExportResult;
  error?: StructuredError;
}
```

## Error Model

### `StructuredError`
All MCP tool errors return this shape (Constitution Principle VI).

```typescript
interface StructuredError {
  code: string;             // e.g., "GE_IMPORT_FAILED"
  message: string;          // Human-readable description
  recoverable: boolean;     // true if caller can retry or roll back
  suggestedTool?: string;   // e.g., "clean_geometry"
}
```

**Error codes**: See `Engineering-Design.md §3.4` for the full error code registry.
